# Velessoft DIY Workbench v0.6

Откройте index.html. Локальные шрифты и ассеты включены. Каталог работает без сети.

## Структура
- index.html: контент разделов.
- tokens.css: базовые стили; catalog.css: оформление каталога и компактные переопределения.
- catalog.js: поиск, маршрутизация, демонстрационные проекты и лаборатория состояний.
- tokens.json: семантические цвета, плотность и типографика (приложение / маркетинг).
- compact.css: отдельные компактные переопределения из v0.5.
- screen-contract.md: заполняемый контракт экрана.
- release-checklist.md: чеклист приёмки продукта.
- assets/: локальные шрифты, SVG-иконки и лицензии; логотипы-концепты.

## Возможности
Поиск по содержимому разделов, переключение темы, создание и редактирование проектов, фильтры, удаление с отменой. Проекты сохраняются в localStorage, когда браузер разрешает. Лаборатория состояний моделирует загрузку, пустоту, ошибку, offline и ограничения доступа; кнопка повтора симулирует успех, запросы не отправляются.

## Границы готовности
Это каталог и локальные прототипы, не готовая библиотека React/Vue. Остальные компоненты — визуальные образцы со спецификациями. Финальный логотип требует согласования; PNG — ранние референсы. Нативного файла Figma и серверной интеграции нет. Для продукта нужно заполнить контракт экрана и пройти проверки доступности и интеграции.

Сторонние лицензии лежат рядом с шрифтами и иконками. Сохраняйте их при распространении. Лицензия библиотек не распространяется автоматически на новые материалы velessoft.
