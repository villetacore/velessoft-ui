# Проверка перед выпуском

- [ ] Основные пользовательские сценарии завершены на реальных данных.
- [ ] Права проверяются сервером, интерфейс объясняет недоступность.
- [ ] Есть загрузка, пустота, ошибка, offline, успех.
- [ ] Повторная отправка не создаёт дубликаты.
- [ ] Ввод сохраняется при ошибках, есть отмена и восстановление где возможно.
- [ ] Клавиатурная навигация и фокус проверены вручную.
- [ ] Проверены контраст, подписи, screen reader и zoom.
- [ ] Проверены 320, 768, 1440 px и длинный контент.
- [ ] Тёмная и светлая темы используют одинаковые семантические роли.
- [ ] Форматы дат, чисел и часовые пояса определены.
- [ ] Пустые и опасные действия не маскируются декоративными элементами.
- [ ] API, документация и токены согласованы с реализацией.
