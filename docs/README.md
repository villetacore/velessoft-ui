## Design resources

[Principles](../design/principles.md) · [Screen contract](../design/screen-contract.md) · [Release checklist](../design/release-checklist.md)

Run `npm run dev`, then open `/public/index.html` for the full design catalog. It includes a state laboratory, screen patterns, brand rules and interaction guidelines. Catalog examples are separate from the packaged implementation. `/examples/html/` shows the CSS + Web Components packages without a framework.
