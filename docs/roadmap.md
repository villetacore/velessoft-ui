# Roadmap

[Documentation](README.md) / Roadmap

## Available

- [x] 35+ React + TypeScript components (forms, feedback, overlays, navigation, data display, layout).
- [x] Framework-agnostic CSS package and dependency-free Web Components for Vue, Svelte, Angular, Solid and HTML.
- [x] Tokens as CSS, SCSS, JS/JSON with types, Tailwind v3 preset and v4 theme; light, dark, nested and auto themes.
- [x] Localizable labels (`VelessoftProvider`, `ru` and `en`).
- [x] Interaction tests for React and Web Components, package install verification, CI on Node 22/24.
- [x] npm publication workflow with provenance and GitHub Pages demo.

## Next

- [ ] First npm registry release (maintainer bootstrap, see [releasing](releasing.md)).
- [ ] Browser-level keyboard and focus tests (Playwright) and automated axe checks.
- [ ] Combobox / autocomplete, date picker, file upload, command palette.
- [ ] Popover with collision handling for tooltips.
- [ ] Optional thin Vue and Svelte wrappers with typed props and `v-model`.
- [ ] Storybook-style documentation site with live props.

Requests are welcome through issues. No release dates are promised here.
