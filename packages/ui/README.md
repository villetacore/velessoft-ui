# @velessoft/ui

Part of **Velessoft UI**, an experimental design system by **villetacore**.

[Repository and screenshots](https://github.com/villetacore/velessoft-ui) · [Documentation](https://github.com/villetacore/velessoft-ui/tree/main/docs)

Version 0.1.0. MIT © 2026 villetacore.

## Usage

```tsx
import { Button, Input } from '@velessoft/ui';
import '@velessoft/tokens/tokens.css';
import '@velessoft/ui/styles.css';
```

Provide React and React DOM 18+. Tested in this repository with React 19. ESM and TypeScript declarations are included. Import tokens before styles. Components: Button, Input, Textarea, Select, Checkbox, Badge, Alert, Dialog.
