# Contributing

Maintained by villetacore. Discuss substantial API or visual changes in an issue first.

1. Run `npm ci` and `npm run dev`.
2. Keep styles scoped to `vs-` classes. Use semantic tokens.
3. Document props, keyboard interaction, states and responsive behavior.
4. Add meaningful interaction tests; run `npm run check`.
5. Include screenshots for UI changes and describe limitations.

Preserve your own Git authorship when contributing. Do not impersonate the maintainer. Contributions are accepted under the repository MIT license. Never commit secrets or real customer data.
